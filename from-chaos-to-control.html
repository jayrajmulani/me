Infrastructure automation on Google Cloud Platform with Terraform and Ansible. End-to-end CI/CD pipeline with monitoring and disaster recovery.

What It Does

From Chaos to Control is a complete DevOps project that demonstrates the full lifecycle of infrastructure automation. It takes a raw GCP account and provisions a production-ready environment using infrastructure-as-code, then sets up continuous integration and deployment, monitoring, and disaster recovery.

The project is structured as a hands-on tutorial — each stage builds on the last, from infrastructure provisioning through monitoring. It's designed to be practical and reproducible, not just theoretical.

Key Features

  • Infrastructure as Code with Terraform modules for compute, networking, storage, and IAM policies
  • Configuration management with Ansible playbooks for application deployment and system hardening
  • Container orchestration with Docker Compose for local development and Kubernetes for production
  • CI/CD pipeline with Jenkins and GitHub Actions, including automated testing and deployment stages
  • Monitoring and alerting with Prometheus and Grafana dashboards for system metrics
  • Disaster recovery setup with automated backups, backup testing, and documented recovery procedures
