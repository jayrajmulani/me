EduSetu

A full-stack academic platform for connecting students and educators. Built with Flask, React, and PostgreSQL as a submitted course assignment.

Submitted Assignment

Tech Stack

Flask React PostgreSQL JavaScript REST APIs

What It Does

EduSetu is an educational platform that connects students with educators. The name combines "Edu" (education) with "Setu" (bridge in Sanskrit), reflecting its purpose: bridging the gap between learners and teachers.

The system provides a full-featured platform with user authentication, course discovery, scheduling, and communication tools. Students can browse available educators, view profiles, book sessions, and track their learning progress. Educators can manage their availability, set rates, and track their students.
