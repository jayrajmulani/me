Inaudible

An ML system that translates English text and audio into American Sign Language video output. Built as an undergraduate capstone project using Python and deep learning techniques.

Source Code Not Available

Tech Stack

Python Deep Learning Computer Vision MediaPipe OpenCV Speech Recognition

What It Does

Inaudible is a sign language translator that bridges the communication gap between hearing/non-signing individuals and the Deaf community. The system accepts English input in two forms — typed text or spoken audio — and outputs a realistic ASL video representation.

The pipeline processes the input through natural language understanding, maps English sentences to their ASL sign equivalents, and generates frame-by-frame video output using computer vision techniques. The result is a fluid video that demonstrates proper ASL hand gestures and facial expressions for the given English input.
