What It Does

Raahee ERP is a full enterprise resource planning system built for a manufacturing company. It handles everything from order management and inventory tracking to invoicing and billing — all through a unified web interface.

The system uses a multi-tenant architecture, allowing multiple organizations to run on the same instance with complete data isolation. Authentication and authorization are handled through Keycloak with OAuth2/OIDC integration.

Key Features

  • Order management with real-time tracking and status updates across the supply chain
  • Multi-tenant architecture with data isolation per organization
  • Inventory management with stock alerts and automated reorder points
  • Invoicing and billing module with PDF generation and email delivery via AWS SES
  • Image processing pipeline using AWS Lambda for document scanning and OCR
  • Localstack-based local development environment for testing AWS services without cloud costs
