WolfMedia

A database-backed media streaming service with royalty tracking, podcast analytics, and content recommendation. Designed for scalability and query performance.

GitHub

Tech Stack

Java Spring Boot PostgreSQL ER Modeling SQL REST APIs

What It Does

WolfMedia is a media streaming platform built around a carefully designed relational database schema. The system manages music, podcasts, and user subscriptions through a unified API, with specialized modules for royalty calculations and content analytics.

The database schema was designed from the ground up, with careful attention to normalization, query performance, and data integrity. The system supports complex queries for analytics — tracking listening patterns, calculating creator royalties across multiple streams, and generating content recommendation suggestions based on user behavior.

Key Features

  • Royalty tracking system that calculates creator payouts based on stream count, subscription tier, and region
  • Podcast analytics dashboard with engagement metrics, listener demographics, and trend analysis
  • Content recommendation engine using listening history and genre preferences
  • Normalized database schema with 12+ tables, foreign key constraints, and indexed queries
  • Spring Boot REST API serving media metadata, user data, and analytics endpoints
