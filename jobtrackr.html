JobTrackr

End-to-end job search tracker with real-time status updates, custom notifications, and resume analysis. Built with Angular and Spring Boot.

GitHub

Tech Stack

Angular Spring Boot AWS MySQL REST APIs

What It Does

JobTrackr is a job search management tool that helps users track their applications across multiple platforms. Instead of juggling tabs on LinkedIn, Indeed, and company portals, everything lives in one dashboard.

The system provides a centralized view of all job applications, real-time status updates, custom notifications for deadlines and follow-ups, and a resume analysis feature that scores and suggests improvements based on job descriptions.

Key Features

  • Dashboard with search and filter — find applications by company, status, date, or tag
  • Real-time status tracking — update application stages from applied to interview to offer
  • Custom notifications for deadlines, follow-ups, and new opportunities
  • Resume analysis that scores your resume against job descriptions
  • Cloud deployment on AWS using Elastic Beanstalk, RDS, and S3
