Excel Data Aggregation

A tool that parses stock market data from Excel files and aggregates it into meaningful reports for investment analysis.

Client Confidential

Tech Stack

Python Web Scraping openpyxl pandas Data Processing

What It Does

This was a freelance project where I built a tool to process and aggregate stock market data for a client. The raw data came in messy Excel files — different column formats, inconsistent dates, duplicate entries — and needed to be transformed into clean, actionable reports.

The tool handles data extraction, cleaning, and aggregation in a single pipeline. It parses multiple Excel file formats, normalizes the data structures, calculates key metrics (moving averages, percentage changes, volume analysis), and outputs summarized reports in a readable format.
